# Git Leaf marketing

English | [简体中文](README.zh-CN.md)

This directory is the long-term workspace for Git Leaf positioning and open-source promotion. It records
the product direction that is already established. Campaign execution and agent operating strategies
should be designed only when that work actually begins.

The baseline definition is:

> Git Leaf is a human-friendly workspace for every employee in an AI-native company that manages
> knowledge with Git.

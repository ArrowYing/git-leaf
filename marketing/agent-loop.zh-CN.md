# Agent 推广方向

[Marketing index](README.zh-CN.md) | 简体中文

Git Leaf 希望把项目推广本身也作为一项 AI-native 实践，未来尽可能由 Agent 完成信息收集、内容生产、渠道执行和
效果反馈。

这项实践服务产品推广，但不改变 Git Leaf 的类别：产品仍是面向 Git 知识库的桌面 App，AI-native 公司只是其中
一个重要场景。Agent 产生的传播材料必须遵守 [产品定位](positioning.zh-CN.md) 和
[对外传播](go-to-market.zh-CN.md) 的文案、证据和公开发布边界。

当前只确认这个长期方向，尚未确定具体运行策略。渠道选择、发布方式、人工参与边界、指标、活动记录和停止条件等问题，
等项目完成开源准备并真正开始推广时再结合当时情况设计，不在现阶段提前规定。

# Git Leaf Marketing

[English](README.md) | 简体中文

本目录是 Git Leaf 产品传播和开源推广的长期工作区。当前先沉淀已经明确的产品定位和开源方向；具体推广动作及
Agent 运行策略在真正开始推广前再单独设计。

Git Leaf 的基础定义是：

> Git Leaf 是 AI-native 公司使用 Git 管理知识时，提供给所有员工的人类友好工作台。

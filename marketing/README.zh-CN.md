# Git Leaf Marketing

[English](README.md) | 简体中文

本目录是 Git Leaf 产品定位和开源推广的长期文档工作区。当前先沉淀已经明确的产品方向；具体推广动作及 Agent
运行策略在真正开始推广前再单独设计。

Git Leaf 的基础定义是：

> 面向 Git 知识库的桌面应用。
>
> 无需直接操作 Git 或 Markdown，即可打开并维护知识库。
>
> 任何人都可以使用 Git Leaf，AI Agent 则直接使用 Git 中的同一份文件。

Git Leaf 是 App；它打开的 Git 仓库才是知识库，也是内容事实源。AI-native 公司是重要的旗舰场景和早期组织用户，
但不是产品类别的限制。

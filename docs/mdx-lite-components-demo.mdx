# MDX-lite component demo

[Documentation index](README.md)

This fixture exercises every MDX-lite component currently supported by Git Leaf. Its numbers and flows
are sample data for visual validation, not business facts. See the
[MDX-lite renderer reference](mdx-lite-guide.md) for syntax and boundaries.

| Component | What this fixture checks |
| --- | --- |
| `DataTable` | Structured detail and wide-table behavior |
| `Timeline` | Milestones, progress, and risk states |
| `Chart` | Line, bar, grouped, stacked, and combo charts |
| `DecisionBox` | Decision, rationale, tradeoffs, reconsideration |
| `MetricGrid` | Small headline metric sets |
| `FlowDiagram` | Main processes and agent handoffs |
